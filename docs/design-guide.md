# 🎨 [디자인 가이드] 놓칠뻔 프로젝트

## 1. 디자인 컨셉 & 컬러
- **톤앤매너:** 신뢰감은 유지하되 딱딱하지 않고 코믹하고 캐주얼한 느낌 (라이트 모드, 세부 디테일은 Claude에게 위임). 문구는 docs/requirements.md의 "톤앤매너" 표를 그대로 사용.
- **로고 아이콘:** 경고성 아이콘이 아니라 윙크하는 표정 아이콘 사용 (lucide-react의 웃는 눈 계열 아이콘 또는 이모지 😉 활용 가능), 색상은 앰버 계열
- **포인트 컬러:** Amber/Orange 계열 (`#BA7517`, `bg-amber-600`) — "하마터면 놓칠 뻔"이라는 아차 싶은 느낌과 장난스러움을 동시에 표현. 정부 서비스처럼 딱딱한 Blue보다 훨씬 친근함
- **카테고리 배지 컬러:** 주거(Blue), 금융·자산형성(Teal), 취업(Amber), 창업(Purple), 신혼부부·결혼(Pink), 임신·출산·육아(Coral), 어르신·노후(Green), 교육(Red), 생활·복지(Gray) — 9개 카테고리 각각 다른 색상 배지 사용
- **카테고리별 아이콘 (lucide-react 또는 Tabler 아이콘 기준):**
  | 카테고리 | 아이콘 |
  |---|---|
  | 주거 | home (집) |
  | 금융·자산형성 | piggy-bank (돼지저금통) |
  | 취업 | briefcase (서류가방) |
  | 창업 | rocket (로켓) |
  | 신혼부부·결혼 | heart (하트) |
  | 임신·출산·육아 | stroller/baby-carriage (유모차) |
  | 어르신·노후 | sunset (노을) |
  | 교육 | school/graduation-cap (학사모) |
  | 생활·복지 | first-aid-kit (구급함) |

## 2. 컴포넌트 스타일 (Tailwind CSS)
- **카드 레이아웃:** 모바일 퍼스트(`max-w-md`), 부드러운 라운딩(`rounded-2xl`), 은은한 그림자(`shadow-sm`)
- **버튼 및 인터랙션:** [신청 바로가기] 버튼은 외부 링크임을 알 수 있도록 아이콘(화살표) 포함, `hover:scale-105 transition-all`
- **입력 화면:** 드롭다운과 선택지 위주로 구성해서 타이핑 최소화 (사용성 우선)
- **카테고리 필터 pill:** 결과 화면 상단에 가로 스크롤 가능한 pill 형태 버튼으로 배치, 선택된 카테고리는 진하게 강조
- **내 정보 칩:** 결과 화면 헤더 우측에 작은 버튼 형태로 배치, 클릭 시 입력 화면으로 부드럽게 전환(라우팅)
- **결과 화면:** 카테고리별 섹션 헤더 + 아이콘 + 결과 개수를 표시해서 한눈에 분류가 보이게 구성
